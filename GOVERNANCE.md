# Governance

The repositories are maintained in public under a maintainer-led model. The owner is the final decision maker for releases, security response, repository administration, and accepted architecture.

Material decisions should be recorded in public issues, accepted specifications, or architecture decision records. Consensus is preferred; when it is unavailable, the maintainer records the decision and rationale so new evidence can revisit it.

Anyone may report defects, join discussions, review contracts, propose changes, and submit pull requests. Sustained contributors may receive triage or write access when it reduces coordination cost without weakening review boundaries. Repository access does not override project-specific review, evidence, or security requirements.
