# Shared community health files

This repository publishes the default contribution, security, support, conduct, issue, and pull-request guidance for public repositories owned by [`iteathen`](https://github.com/iteathen).

GitHub uses these files only when a repository does not provide a more specific local version. Project-local architecture, accepted specifications, support status, and contribution instructions remain authoritative.

The public account overview is maintained in [`profile/README.md`](profile/README.md).
