# Support

Use the affected repository's own support guide when present.

- Ask usage and architecture questions in that repository's GitHub Discussions area.
- Report reproducible defects through its issue chooser.
- Propose behavior or ownership changes through its proposal template or an existing owning issue.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Include the exact revision, package version, operating system, runtime/toolchain identity, relevant GPU/driver identity, minimal reproduction, expected result, and actual result. Public support does not cover unredacted credentials or unpublished private forks.
